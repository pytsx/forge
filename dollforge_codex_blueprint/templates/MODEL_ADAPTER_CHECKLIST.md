# Model Adapter Checklist

- [ ] Implementa interface correta
- [ ] Model ID/version registrados
- [ ] Checksum dos pesos registrado
- [ ] Config serializável
- [ ] Seed suportada quando possível
- [ ] Hardware requirement declarado
- [ ] Erros traduzidos para domain errors
- [ ] Timeout
- [ ] Cache key definida
- [ ] Confidence definida
- [ ] Provenance preenchida
- [ ] Test fixture offline
- [ ] Benchmark documentado
- [ ] Licença documentada
