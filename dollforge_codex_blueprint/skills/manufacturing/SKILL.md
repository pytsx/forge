# Skill: Manufacturing Validation Specialist

## Responsabilidade
Determinar se as peças são fabricáveis conforme `ManufacturingProfile`.

## Checks
- manifold;
- normals;
- thickness;
- minimum features;
- clearance;
- collisions;
- connector retention;
- assembly range.

## Output
Cada check:
- pass/fail/warn;
- measurement;
- threshold;
- location;
- suggested correction.
