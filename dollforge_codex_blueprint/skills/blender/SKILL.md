# Skill: Blender Build Specialist

## Responsabilidade
Converter artefatos validados em um `.blend` editável.

## Deve
- operar headless;
- criar collections padronizadas;
- preservar source meshes;
- aplicar nomes estáveis;
- criar connector geometry procedural;
- salvar arquivo final;
- exportar relatório.

## Não deve
- tomar decisões semânticas novas silenciosamente;
- rodar training;
- virar banco de dados;
- ser a única fonte de medidas.
